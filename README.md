# Elysia with Bun runtime

## Getting Started
To get started with this template, simply paste this command into your terminal:
```bash
bun create elysia ./elysia-example
```

## Development
To start the development server run:
```bash
bun run dev
```

Open http://localhost:3000/ with your browser to see the result.

## Ideas Folder Integration
This project is linked with an external "My Ideas" folder to provide additional context and ideas without duplicating files.

To initialize the connection, run:
```bash
bun run link-ideas
```
*(Note: Creating symbolic links on Windows may require running your terminal as an Administrator, or having Developer Mode enabled in Windows Settings.)*
